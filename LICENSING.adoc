== Where the texts live

* link:LICENSE[`LICENSE`] — the MPL-2.0 text. This is the file GitHub detects; it is the
canonical copy.
* link:LICENSES/MPL-2.0.txt[`LICENSES/MPL-2.0.txt`] — byte-identical duplicate, kept for
https://reuse.software/[REUSE] tooling.
* link:LICENSES/CC-BY-SA-4.0.txt[`LICENSES/CC-BY-SA-4.0.txt`] — the documentation licence text.

== The rule for contributors

Every source and documentation file carries an SPDX identifier *on line 1*:

[source,elixir]
----
# SPDX-License-Identifier: MPL-2.0
----

[source,markdown]
----
<!-- SPDX-License-Identifier: CC-BY-SA-4.0 -->
----

Line 1 is not a style preference. The repository's licence gate reads `head -1` only, so an
identifier on line 3 is invisible to it and the file reads as unlicensed.

If a file already has an identifier in the wrong place, *move it*. Never add a second one:
a file with two identifiers is worse than a file with none, because the shadowed one is
silently ignored while looking correct to a human reader.

== What this project is _not_ licensed under

Three sources in this repository have historically suggested otherwise. All three are
resolved or annotated; none reflects the actual licensing:

* *AGPL-3.0-or-later.* Nine `.github/` issue, discussion and settings templates carried
AGPL SPDX headers — inherited template drift, never a deliberate relicensing. Corrected to
`MPL-2.0` on 2026-08-07, and the orphaned `LICENSES/AGPL-3.0-or-later.txt` removed.
* *"AGPL {plus} Palimpsest dual license."* Stated by link:RSR_OUTLINE.adoc[`RSR_OUTLINE.adoc`],
which is an inherited copy of the generic RSR _template_ outline describing a different
repository. It is annotated to say so. It also refers to `LICENSE.txt`; this project's file
is `LICENSE`.
* *PMPL-1.0-or-later.* The README's licence badge alt-text read `PMPL-1.0-or-later` while
its image read `MPL-2.0`. Corrected on 2026-08-07. (A sibling repository, svalinn, did have
a genuine PMPL→MPL migration; stapeln did not — it has been MPL-2.0 throughout.)

== Verifying

[source,sh]
----
just must-license-present     # LICENSE file exists
just trust-license-content    # LICENSE contains the expected SPDX identifier
just must-spdx-headers        # source files carry an SPDX header

# distribution across the tree — expect only MPL-2.0 and CC-BY-SA-4.0
grep -rho "SPDX-License-Identifier: [A-Za-z0-9.+-]*" --include="*" . \
  | grep -v node_modules | sort | uniq -c | sort -rn
----

As of 2026-08-07 that last command reports *491 MPL-2.0* and *179 CC-BY-SA-4.0*, and
nothing else. Any other identifier appearing in that output is a regression.
