# stapeln Frontend

This is the **stapeln UI application** (not the DOM‑mounter library).

## What This Is

- The visual, end‑user app for designing secure container stacks.
- Implemented with affinescript (TEA) and served with Deno.

## Quick Start

```bash
cd /var$REPOS_DIR/stapeln/frontend
affinescript build
deno task dev
```

## Notes

- The DOM‑mounter workstream has been extracted to `/var$REPOS_DIR/stapeln-dom-mounter`.
