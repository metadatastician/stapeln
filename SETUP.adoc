= stapeln Setup Guide

[[installation-no-npmnodejs]]
== Installation (No npm/Node.js!)

stapeln follows hyperpolymath language policy: *Deno only, no npm/Node.js*.

=== Prerequisites

[arabic]
. *Deno 2.0{plus}*

[source,bash]
----
# Install Deno (if not already installed)
curl -fsSL https://deno.land/install.sh | sh

# Add to PATH (add to ~/.bashrc)
export PATH="$HOME/.deno/bin:$PATH"
----

[arabic, start=2]
. *affinescript Compiler via Deno*

[source,bash]
----
# Install affinescript using Deno's npm compatibility
deno install --allow-read --allow-write --allow-env --allow-run \
  -n affinescript \
  npm:affinescript@11

# Verify installation
affinescript -version
----

[arabic, start=3]
. *Elixir {plus} Phoenix (for backend)*

[source,bash]
----
# Fedora
sudo dnf install elixir

# Install Phoenix
mix archive.install hex phx_new
----

[arabic, start=4]
. *Idris2 (for formal proofs)*

[source,bash]
----
# Fedora
sudo dnf install idris2
----

[arabic, start=5]
. *Rust (for codegen NIFs)*

[source,bash]
----
# Already installed on your system
rustc --version
----

[[frontend-setup-affinescript--deno]]
== Frontend Setup (affinescript {plus} Deno)

[source,bash]
----
cd ~/Documents/hyperpolymath-repos/stapeln/frontend

# Compile affinescript to JavaScript
affinescript build

# Start Deno dev server
deno task dev

# Open browser
xdg-open http://localhost:8000
----

=== Development Workflow

[source,bash]
----
# Watch mode (recompile on save)
affinescript build -w &

# In another terminal, run dev server
deno task dev
----

=== Deno Permissions

stapeln requires these Deno permissions:

* `--allow-read` - Read frontend files
* `--allow-write` - Write compiled output
* `--allow-net` - HTTP server
* `--allow-env` - Environment variables

These are declared in `deno.json` tasks.

== Troubleshooting

=== "affinescript: command not found"

The Deno install didn't add to PATH. Add to `~/.bashrc`:

[source,bash]
----
export PATH="$HOME/.deno/bin:$PATH"
----

=== "Cannot find module 'npm:@affinescript/core'"

Deno's npm compatibility needs the import map. Check `frontend/import_map.json`:

[source,json]
----
{
  "imports": {
    "@affinescript/core": "https://esm.sh/@affinescript/core@1.0.0"
  }
}
----

=== affinescript compilation errors

Check `frontend/affinescript.json` for correct configuration:

* `"module": "es6"`
* `"suffix": ".res.js"`
* `"in-source": true`

== Environment Variables

Create `frontend/.env`:

[source,bash]
----
# Backend API
STAPELN_API_URL=http://localhost:4010

# GraphQL endpoint
STAPELN_GRAPHQL_URL=http://localhost:4010/graphql

# WebSocket
STAPELN_WS_URL=ws://localhost:4010/socket
----

== No npm/Node.js Required! ✅

stapeln is 100% Deno-based for JavaScript runtime. We use:

* ✅ Deno for runtime
* ✅ Deno's npm: specifier for affinescript compiler
* ✅ Deno's import maps for dependencies
* ❌ No package.json
* ❌ No node_modules/
* ❌ No npm install

This follows hyperpolymath standards and ensures security-first execution.
